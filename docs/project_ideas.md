# Project 5.5 - Rolling Correlation Dashboard

## Goal

Extend the static currency correlation matrix into a rolling correlation dashboard to see how relationships between currency pairs change over time.

## Planned Features

- Download historical FX data
- Calculate daily returns
- Calculate rolling Pearson correlations
- Display an updating correlation heatmap
- Experiment with different rolling windows (30, 60 and 252 trading days)
- Compare periods of high and low market correlation

## Stretch Goals

- Animate the heatmap through time
- Refresh the dashboard with the latest market data
- Add filters for different currency groups
